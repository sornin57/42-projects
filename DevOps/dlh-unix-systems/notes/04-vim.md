# Vim Basics

Vim is a terminal text editor.

## Modes

- Normal mode: move, copy, delete, save.
- Insert mode: write text.
- Command mode: run editor commands.

## Useful Keys

```text
i       insert mode
Esc     normal mode
:w      save
:q      quit
:wq     save and quit
:q!     quit without saving
yy      copy current line
p       paste copied line
dd      delete current line
```
