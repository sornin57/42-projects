# Python00 - Growing Code

First module of the Python Piscine.

## Goal

Practice the basics of Python through small functions based on a garden theme.

## Skills Practiced

- Writing simple functions
- Using `print()`
- Reading input with `input()`
- Converting values with `int()`
- Using conditions with `if` and `else`
- Using loops with `range()`
- Writing a basic recursive function
- Adding type hints
- Matching exact output formats

## Exercises

- `ex0` - Print a welcome message
- `ex1` - Ask for a garden name and display its status
- `ex2` - Calculate the area of a garden plot
- `ex3` - Add harvest values from three days
- `ex4` - Check if a plant is ready to harvest
- `ex5` - Remind when plants need water
- `ex6` - Count days until harvest with iterative and recursive functions
- `ex7` - Display seed inventory with type annotations

## How To Test

Run the helper from inside each exercise folder:

```bash
python3 ../main.py
```

Then select the exercise number.
